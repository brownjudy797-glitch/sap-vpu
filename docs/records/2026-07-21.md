# 2026-07-21 Complete Subsystem Synthesis Record

## Objective

Measure the implementation cost of `sap_vpu_subsystem`, including the tiled
GEMM scheduler, four-word register scratchpads, and single-outstanding OBI
read/write data mover, relative to `sap_vpu_core`.

## FPGA Result

Windows Vivado 2023.2 implemented the core and subsystem for
`xc7a35tcsg324-1` in out-of-context mode. OOC is required because the subsystem
is internal SoC IP and its 223 raw I/O bits exceed the package's 210 user I/Os.

| Top | Clock MHz | Worst slack ns | LUT | FF | DSP | BRAM |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| `sap_vpu_core` | 100 | 2.191 | 1817 | 729 | 0 | 0 |
| `sap_vpu_subsystem` | 100 | 1.816 | 2741 | 1332 | 0 | 0 |
| `sap_vpu_core` | 140 | 0.090 | 1817 | 742 | 0 | 0 |
| `sap_vpu_subsystem` | 140 | 0.091 | 2752 | 1332 | 0 | 0 |

At 140 MHz the subsystem delta is +935 LUTs (+51.5%) and +590 FFs (+79.5%).
This is comparative internal-IP evidence. Missing OOC `HD.CLK_SRC` and
`HD.PARTPIN_LOCS` constraints prevent treating it as board timing signoff.

## ASIC Result

DC L-2016.03-SP1 successfully analyzed, elaborated, linked, and checked the
complete subsystem against TSMC28 `tt0p9v85c` at 10 ns. Three bounded mapping
configurations then ended in DC internal fatal errors. The lowest-effort run
reached design-rule fixing before failing while reloading the TSMC28 `.db`.

No mapped DDC, netlist, area report, timing report, or power report was
produced. Therefore this checkpoint contributes no complete-subsystem ASIC PPA
number. Crash snapshots remain in ignored local `work/dc/tsmc28/` directories.

## Decision

- Keep the parameterized core/subsystem FPGA and DC entry points.
- Stop retrying the same DC 2016 installation with random mapping flags.
- Use a newer compatible DC release or a validated regenerated TSMC28 `.db` for
  the next complete-subsystem ASIC run.
- Continue FPGA subsystem activity and larger TinyViT mapping while that
  toolchain issue is repaired.
