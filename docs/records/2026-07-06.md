- Added `docs/SAP_VPU_FRAMEWORK.md` as the documentation entry point for the
  framework figure and linked it from the project document index.
- Added an `adaptive_unstructured` TinyViT smoke row using INT4 bitmap `0x55`

  traffic, and CSV summary checks.
- Expanded low-bit and ablation TinyViT policy rows to a 2-token x
  2-output-channel macro-tile, aligning their VDOT count and observed RAM tile

  each block, preserving dense output and VDOT count while reducing observed RAM

  block-local operand/weight reuse, preserving the adaptive output, skip count,

  runs Vivado synthesis/place/route/report for `sap_vpu_core`, and

  power report boundary.

  without using an open PDK library. The wrapper intentionally does not source
  the local Synopsys environment file by default so unrelated open-library
