# SAP-VPU Work Records - 2026-07-24 - Sparse FPGA policy power

## Objective

Measure dense and selected TinyViT K=128 FC2 sparsity policies with the same
current `sap_vpu_subsystem` FPGA netlist, routed checkpoint, clock, fixture, and
iteration count.

## Functional Result

The subsystem gate testbench now accepts `mlp2_dense`, `fc2_dense`,
`fc2_global_l1_6p25`, and `fc2_l1_budget_2pct`. RTL simulation checks exact
aggregate outputs and reports these per-workload command counts:

| Policy | VDOTs | RAM reads | RAM writes |
| --- | ---: | ---: | ---: |
| `fc2_dense` | 128 | 128 | 64 |
| `fc2_global_l1_6p25` | 120 | 124 | 64 |
| `fc2_l1_budget_2pct` | 122 | 125 | 64 |

The WSL Ubuntu 20.04 Python 3.8 process intermittently corrupted importlib and
built-in calls. Fixture generation was therefore run with the existing isolated
Windows model Python. The generated data and all four Verilator modes passed.

## FPGA Implementation

The July 21 DCP predated the July 24 descriptor/group-skip RTL and failed the
sparse gate check. The current RTL was reimplemented with Windows Vivado 2023.2,
Artix-7 `xc7a35tcsg324-1`, 140 MHz, OOC mode, and `Explore` directives. Local
NTFS staging was required because the synthesis helper could not run reliably
from the WSL UNC mapping.

| Top | LUT | FF | DSP | BRAM | WNS ns |
| --- | ---: | ---: | ---: | ---: | ---: |
| `sap_vpu_core` | 1862 | 788 | 0 | 0 | +0.074 |
| `sap_vpu_subsystem` | 2523 | 1303 | 0 | 0 | +0.025 |

The subsystem increment is 661 LUTs (+35.5%) and 515 FFs (+65.4%). These are
internal-IP OOC results, not full-SoC or board signoff.

6142/6200 routed nets (99.06%) with High confidence.

Vivado reports dynamic power to 0.001 W and rounds all policies to 0.014 W.
The valid comparison is dynamic energy and latency per matched workload, not a
resolved average-power difference. CPU, external RAM, full SoC, board power,
and end-to-end TinyViT execution remain excluded.
